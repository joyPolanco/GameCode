### README.md — GameSoft (Análisis del Mercado de Videojuegos 2024)

## Descripción

GameSoft es una aplicación desarrollada en Python orientada al análisis del mercado de videojuegos. Permite explorar datos, identificar tendencias y generar visualizaciones para comprender el comportamiento de la industria.

---

## Objetivo del proyecto

El objetivo principal es transformar datos de videojuegos en información útil mediante técnicas de análisis y visualización, facilitando la toma de decisiones basada en datos.

---

## Funcionalidades

* Carga y limpieza de datos desde archivos CSV.
* Análisis exploratorio de datos (EDA):

  * Géneros más frecuentes.
  * Plataformas más utilizadas.
* Generación de visualizaciones:

  * Evolución de la industria.
  * Análisis por género.
* Interfaz gráfica con Tkinter.
* Navegación entre secciones:

  * Inicio
  * Gráficas
  * Información técnica
  * Sobre nosotros

---

## Tecnologías utilizadas

* Python
* Pandas
* Matplotlib
* Seaborn
* Tkinter
* Pillow

---

## Estructura del proyecto

```bash
data/               # Dataset en CSV
assets/             # Imágenes e íconos
modules/            # Lógica del sistema
    data_loader.py  # Carga de datos
    grafic.py       # Control de gráficos
    view_grafic.py  # Interfaz de visualización
grafic_fun/         # Funciones de análisis y gráficos
main.py             # Punto de entrada de la aplicación
```

---

## Análisis de datos (EDA)

El sistema realiza un análisis exploratorio básico para identificar:

* Distribución de géneros de videojuegos.
* Plataformas más frecuentes en el dataset.
* Tendencias generales del mercado.

---

## Interfaz del sistema

La aplicación incluye una interfaz gráfica desarrollada en Tkinter con:

* Pantalla de inicio con presentación del proyecto.
* Menú de navegación superior.
* Visualización de gráficos interactivos.
* Sección de información técnica del dataset.
* Sección de información del equipo de desarrollo.

---

## Instalación y ejecución

### Instalación de dependencias

```bash
pip install pandas matplotlib seaborn pillow
```

### Ejecución del proyecto

```bash
python main.py
```
